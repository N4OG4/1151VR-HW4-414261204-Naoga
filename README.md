# 製作流程和相關操作
首先，在 unity asset store 搜尋素材導入unity hub，

音效要另外找。

於 github 開啟新 repo 設定為"公開" .gitignore 套用 unity，

當安裝好 unity hub 後，開啟專案，

將搜索到的素材下載下來導入專案 Assets 目錄，再視窗中拖曳至 Scene 中，

放置隱形的cube作為得分的依據，

給飛機 new script, rigid body, 將程式寫入，把音效變數對上Assets的檔案

接著將相機設為player子類別，點擊視窗上方的 ▶ 執行專案，

確認畫面中有顯示模型後，開啟螢幕錄影再執行一次

最後將影片上傳至 YouTube。
